# Foco

Painel pessoal de produtividade estático, pensado primeiro para celular. Não há backend nem dependências: os dados ficam no `localStorage` do navegador e podem ser exportados em JSON.

## Publicar no GitHub Pages

1. Envie estes arquivos para a raiz de um repositório GitHub.
2. Em **Settings → Pages**, escolha **Deploy from a branch**.
3. Selecione a branch `main` e a pasta `/(root)`.
4. Salve. O GitHub fornecerá o endereço do site.

Após a primeira abertura, o app pode funcionar offline graças ao cache local. Para preservar ou migrar os dados entre aparelhos, use **Ajustes → Exportar backup** e depois **Importar backup**.
